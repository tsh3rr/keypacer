Sur un clavier AZERTY français, l'arobase se tape avec <kbd>AltGr</kbd> + <kbd>à</kbd> (la touche du 0). L'euro s'obtient avec <kbd>AltGr</kbd> + <kbd>E</kbd>, le dièse avec <kbd>AltGr</kbd> + <kbd>"</kbd> (la touche du 3) et les accolades avec <kbd>AltGr</kbd> + <kbd>'</kbd> et <kbd>AltGr</kbd> + <kbd>=</kbd>. Sur Mac, la plupart de ces symboles sont ailleurs et passent par la touche Option <kbd>⌥</kbd>.

Tu as besoin de ces caractères tout le temps : dans les adresses e-mail, les prix, les formules et le code. Si tu dois les chercher à chaque fois, tu perds ton rythme. Voici où ils se trouvent, avec quel doigt les taper et comment les retenir.

## Les trois niveaux d'une touche

Sur un clavier AZERTY, une touche porte jusqu'à trois caractères :

- **en bas à gauche :** sans touche supplémentaire, par exemple <kbd>è</kbd>,
- **en haut à gauche :** avec Maj <kbd>⇧</kbd>, par exemple le chiffre <kbd>7</kbd>,
- **en bas à droite :** avec <kbd>AltGr</kbd>, par exemple <kbd>`</kbd>.

Particularité de l'AZERTY : **les chiffres demandent Maj.** Ce sont les accents et les symboles qui sont en accès direct.

<kbd>AltGr</kbd> se trouve à droite de la barre d'espace. En dactylographie, on la maintient avec le pouce droit. Sous Windows, <kbd>Ctrl</kbd> + <kbd>Alt</kbd> fonctionne comme AltGr, ce qui aide pour les caractères du côté droit (on y revient plus bas).

## Tous les symboles AltGr (Windows et Linux)

| Symbole | Combinaison | Doigt pour la touche |
| --- | --- | --- |
| ~ | <kbd>AltGr</kbd> + <kbd>é</kbd>, puis Espace | annulaire gauche |
| # | <kbd>AltGr</kbd> + <kbd>"</kbd> | majeur gauche |
| { | <kbd>AltGr</kbd> + <kbd>'</kbd> | index gauche |
| [ | <kbd>AltGr</kbd> + <kbd>(</kbd> | index gauche |
| \| | <kbd>AltGr</kbd> + <kbd>-</kbd> | index droit |
| ` | <kbd>AltGr</kbd> + <kbd>è</kbd>, puis Espace | index droit |
| \\ | <kbd>AltGr</kbd> + <kbd>_</kbd> | majeur droit |
| ^ | <kbd>AltGr</kbd> + <kbd>ç</kbd>, puis Espace | annulaire droit |
| @ | <kbd>AltGr</kbd> + <kbd>à</kbd> | auriculaire droit |
| ] | <kbd>AltGr</kbd> + <kbd>)</kbd> | auriculaire droit |
| } | <kbd>AltGr</kbd> + <kbd>=</kbd> | auriculaire droit |
| € | <kbd>AltGr</kbd> + <kbd>E</kbd> | majeur gauche |
| ¤ | <kbd>AltGr</kbd> + <kbd>$</kbd> | auriculaire droit |

Toutes ces touches sont dans la rangée des chiffres, sauf € et ¤. Le clavier belge est différent : l'arobase y est sur <kbd>AltGr</kbd> + <kbd>é</kbd>. La norme AZERTY de 2019 réorganise aussi les symboles, mais elle reste rare dans le commerce.

## Les caractères avec Maj

La règle de la frappe à dix doigts : **c'est toujours l'autre main qui appuie sur Maj.** Pour le <kbd>7</kbd> (main droite), tu maintiens Maj gauche avec l'auriculaire gauche.

| Caractère | Combinaison | Caractère | Combinaison |
| --- | --- | --- | --- |
| 1 à 0 | <kbd>⇧</kbd> + rangée des chiffres | ? | <kbd>⇧</kbd> + <kbd>,</kbd> |
| ° | <kbd>⇧</kbd> + <kbd>)</kbd> | . | <kbd>⇧</kbd> + <kbd>;</kbd> |
| + | <kbd>⇧</kbd> + <kbd>=</kbd> | / | <kbd>⇧</kbd> + <kbd>:</kbd> |
| £ | <kbd>⇧</kbd> + <kbd>$</kbd> | § | <kbd>⇧</kbd> + <kbd>!</kbd> |
| % | <kbd>⇧</kbd> + <kbd>ù</kbd> | µ | <kbd>⇧</kbd> + <kbd>*</kbd> |
| ¨ | <kbd>⇧</kbd> + <kbd>^</kbd> | > | <kbd>⇧</kbd> + <kbd>&lt;</kbd> |

Le point lui aussi demande Maj sur l'AZERTY. Ça vaut la peine de l'entraîner tôt, puisqu'il termine chaque phrase.

## Touches mortes : ^ et ¨

La touche <kbd>^</kbd> à droite du P est une touche morte : elle pose l'accent sur la lettre suivante. <kbd>^</kbd> puis <kbd>e</kbd> donne ê, <kbd>⇧</kbd> + <kbd>^</kbd> puis <kbd>e</kbd> donne ë. Pour obtenir le signe seul, appuie ensuite sur Espace. C'est pareil pour ~, ` et ^ avec AltGr.

## Ce qui aide pour les caractères à droite

Avec <kbd>AltGr</kbd> + <kbd>à</kbd> ou <kbd>AltGr</kbd> + <kbd>=</kbd>, la main droite travaille double : le pouce maintient AltGr, l'auriculaire s'étire vers le haut. C'est inconfortable au début. Deux façons de faciliter les choses :

- **Tourner légèrement la main.** Laisse le pouce sur AltGr et déplace toute la main un peu vers le haut, au lieu d'étirer seulement le doigt. Reviens ensuite en position de repos.
- **Ctrl + Alt à gauche.** Sous Windows, <kbd>Ctrl</kbd> + <kbd>Alt</kbd> agit comme AltGr. La main gauche maintient les deux touches, la droite tape le caractère. Pour programmer avec beaucoup d'accolades, beaucoup trouvent ça plus agréable.

## Comment apprendre les symboles sans regarder

1. **D'abord le chemin, ensuite la vitesse.** Tape un symbole dix fois de suite lentement en disant à voix basse la combinaison, par exemple « AltGr à ». Ne regarde que la première fois.
2. **Entraîne-toi en contexte réel.** Une @ apparaît presque toujours dans une adresse e-mail, une accolade rarement seule. Tape donc `nom@exemple.fr` ou `if (x) { y }` plutôt que des caractères isolés.
3. **Entraîne les paires ensemble.** Crochets et accolades ouvrants et fermants vont toujours par deux. Une fois `{` acquis, `}` suit vite.
4. **Peu de symboles à la fois.** Prends deux ou trois nouveaux symboles par jour. Une courte répétition quotidienne apporte plus qu'une longue séance.
5. **Ne regarde pas les touches.** Si tu ne sais pas où est un symbole, regarde le tableau plutôt que le clavier. Ta tête apprend ainsi la position et pas le coup d'œil vers le bas.
