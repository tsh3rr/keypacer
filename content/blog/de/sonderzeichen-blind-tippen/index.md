Auf einer deutschen Tastatur tippst du das @-Zeichen mit <kbd>AltGr</kbd> + <kbd>Q</kbd>. Das Euro-Zeichen kommt mit <kbd>AltGr</kbd> + <kbd>E</kbd>, die geschweiften Klammern mit <kbd>AltGr</kbd> + <kbd>7</kbd> und <kbd>AltGr</kbd> + <kbd>0</kbd>. Auf dem Mac nimmst du statt AltGr die Wahltaste <kbd>⌥</kbd>, und viele Zeichen liegen dort woanders.

Diese Zeichen brauchst du ständig: in E-Mail-Adressen, Preisen, Formeln und im Code. Wer sie jedes Mal suchen muss, verliert den Rhythmus. Hier steht, wo sie liegen, mit welchem Finger du sie tippst und wie du sie dir einprägst.

## Die drei Ebenen jeder Taste

Auf einer deutschen Tastatur trägt eine Taste bis zu drei Zeichen:

- **unten links:** ohne Zusatztaste, zum Beispiel <kbd>7</kbd>,
- **oben links:** mit der Umschalttaste <kbd>⇧</kbd>, zum Beispiel <kbd>/</kbd>,
- **unten rechts:** mit <kbd>AltGr</kbd>, zum Beispiel <kbd>{</kbd>.

<kbd>AltGr</kbd> sitzt rechts neben der Leertaste. Im Zehnfingersystem hältst du sie mit dem rechten Daumen. Unter Windows funktioniert statt AltGr auch <kbd>Strg</kbd> + <kbd>Alt</kbd>, das hilft bei Zeichen auf der rechten Seite (mehr dazu unten).

## Alle AltGr-Zeichen auf einen Blick (Windows und Linux)

| Zeichen | Tastenkombination | Finger für die Taste |
| --- | --- | --- |
| @ | <kbd>AltGr</kbd> + <kbd>Q</kbd> | linker kleiner Finger |
| € | <kbd>AltGr</kbd> + <kbd>E</kbd> | linker Mittelfinger |
| { | <kbd>AltGr</kbd> + <kbd>7</kbd> | rechter Zeigefinger |
| [ | <kbd>AltGr</kbd> + <kbd>8</kbd> | rechter Mittelfinger |
| ] | <kbd>AltGr</kbd> + <kbd>9</kbd> | rechter Ringfinger |
| } | <kbd>AltGr</kbd> + <kbd>0</kbd> | rechter kleiner Finger |
| \ | <kbd>AltGr</kbd> + <kbd>ß</kbd> | rechter kleiner Finger |
| ~ | <kbd>AltGr</kbd> + <kbd>+</kbd> | rechter kleiner Finger |
| \| | <kbd>AltGr</kbd> + <kbd>&lt;</kbd> | linker kleiner Finger |
| µ | <kbd>AltGr</kbd> + <kbd>M</kbd> | rechter Zeigefinger |
| ² ³ | <kbd>AltGr</kbd> + <kbd>2</kbd> oder <kbd>3</kbd> | linker Ring- oder Mittelfinger |

Die Taste <kbd>&lt;</kbd> liegt links neben dem <kbd>Y</kbd>. In Österreich ist die Belegung dieselbe. Die Schweizer Tastatur weicht ab, dort liegt das @ zum Beispiel auf <kbd>AltGr</kbd> + <kbd>2</kbd>.

## Die gleichen Zeichen auf dem Mac

| Zeichen | Tastenkombination |
| --- | --- |
| @ | <kbd>⌥</kbd> + <kbd>L</kbd> |
| € | <kbd>⌥</kbd> + <kbd>E</kbd> |
| [ ] | <kbd>⌥</kbd> + <kbd>5</kbd> und <kbd>6</kbd> |
| { } | <kbd>⌥</kbd> + <kbd>8</kbd> und <kbd>9</kbd> |
| \| | <kbd>⌥</kbd> + <kbd>7</kbd> |
| \ | <kbd>⇧</kbd> + <kbd>⌥</kbd> + <kbd>7</kbd> |
| ~ | <kbd>⌥</kbd> + <kbd>N</kbd>, danach Leertaste |

Die Wahltaste gibt es links und rechts. Nimm die auf der anderen Seite als die Zeichentaste, so wie bei der Umschalttaste.

## Zeichen mit der Umschalttaste

Viele Zeichen brauchen nur <kbd>⇧</kbd>. Die Regel im Zehnfingersystem: Die Umschalttaste drückt immer die andere Hand. Für <kbd>/</kbd> (<kbd>⇧</kbd> + <kbd>7</kbd>, rechte Hand) hältst du also die linke Umschalttaste mit dem linken kleinen Finger.

| Zeichen | Kombination | Zeichen | Kombination |
| --- | --- | --- | --- |
| " | <kbd>⇧</kbd> + <kbd>2</kbd> | ( ) | <kbd>⇧</kbd> + <kbd>8</kbd> und <kbd>9</kbd> |
| § | <kbd>⇧</kbd> + <kbd>3</kbd> | = | <kbd>⇧</kbd> + <kbd>0</kbd> |
| $ | <kbd>⇧</kbd> + <kbd>4</kbd> | ? | <kbd>⇧</kbd> + <kbd>ß</kbd> |
| % | <kbd>⇧</kbd> + <kbd>5</kbd> | * | <kbd>⇧</kbd> + <kbd>+</kbd> |
| & | <kbd>⇧</kbd> + <kbd>6</kbd> | ' | <kbd>⇧</kbd> + <kbd>#</kbd> |
| / | <kbd>⇧</kbd> + <kbd>7</kbd> | > | <kbd>⇧</kbd> + <kbd>&lt;</kbd> |

## Tottasten: ^, ´ und `

Die Tasten <kbd>^</kbd> (links neben der <kbd>1</kbd>) und <kbd>´</kbd> (links neben der Rücktaste) sind Tottasten. Sie setzen einen Akzent auf den nächsten Buchstaben: <kbd>´</kbd> und dann <kbd>e</kbd> ergibt é. Willst du das Zeichen allein, drückst du danach die Leertaste. Den Gravis ` bekommst du mit <kbd>⇧</kbd> + <kbd>´</kbd>, ebenfalls gefolgt von der Leertaste.

## Was bei Zeichen auf der rechten Seite hilft

Bei <kbd>AltGr</kbd> + <kbd>0</kbd> oder <kbd>AltGr</kbd> + <kbd>ß</kbd> arbeitet die rechte Hand doppelt: Der Daumen hält AltGr, der kleine Finger streckt sich nach oben. Das ist anfangs unbequem. Zwei Wege machen es leichter:

- **Hand leicht drehen.** Lass den Daumen auf AltGr und bewege die ganze Hand ein Stück nach oben, statt nur den Finger zu strecken. Danach kehrst du zur Grundstellung zurück.
- **Strg + Alt mit links.** Unter Windows wirkt <kbd>Strg</kbd> + <kbd>Alt</kbd> wie AltGr. Die linke Hand hält beide Tasten, die rechte tippt das Zeichen. Gerade beim Programmieren mit vielen Klammern finden das viele angenehmer.

## So lernst du Sonderzeichen ohne Hinschauen

1. **Erst den Weg, dann das Tempo.** Tippe ein Zeichen zehnmal langsam hintereinander und sag dabei leise die Kombination mit, zum Beispiel „AltGr Q“. Schau nur beim ersten Mal hin.
2. **Übe in echten Zusammenhängen.** Ein @ kommt fast immer in einer E-Mail-Adresse vor, eine Klammer selten allein. Tippe also `name@beispiel.de` oder `if (x) { y }` statt einzelner Zeichen.
3. **Übe Paare zusammen.** Öffnende und schließende Klammern liegen nebeneinander. Wer `{` sicher hat, lernt `}` schneller dazu.
4. **Wenige Zeichen auf einmal.** Nimm dir zwei oder drei neue Zeichen pro Tag vor. Kurze tägliche Wiederholung bringt mehr als eine lange Sitzung.
5. **Nicht auf die Tasten schauen.** Wenn du nicht weißt, wo ein Zeichen liegt, schau in die Tabelle statt auf die Tastatur. So lernt dein Kopf die Position und nicht den Blick nach unten.

## Wie Keypacer dabei hilft

Keypacer übt nach den Buchstaben auch Großbuchstaben, Satzzeichen und Ziffern, jeweils mit dem passenden Finger für die Umschalttaste. Die Fingerhilfe zeigt bei jedem Zeichen, welche Taste und welcher Finger dran ist. Zeichen wie @ und geschweifte Klammern stehen noch nicht in den Übungstexten. Für sie sind die Tabellen und Übungen oben der beste Weg.

Wenn dein Blick bei bestimmten Tasten immer noch nach unten wandert, hilft dir [Blind tippen lernen](/de/blog/blind-tippen-lernen/) weiter.
